Política de Privacidad de Sentinel Guard

Última actualización: 26 de septiembre de 2026

1. Responsable

El responsable de Sentinel Guard es:

CookedOficial

Sentinel Guard es un bot de Discord destinado a proporcionar funciones de moderación, seguridad, administración y protección para servidores de Discord.

2. Información que puede procesar Sentinel Guard

Para proporcionar sus funciones, Sentinel Guard puede procesar determinados datos relacionados con Discord, entre ellos:

  • ID de usuario de Discord.
  • ID del servidor de Discord.
  • ID de canales, cuando sea necesario para ejecutar determinadas funciones.
  • Información relacionada con roles y permisos necesarios para comprobar autorizaciones.
  • Información introducida por los usuarios mediante los comandos del bot.
  • Información necesaria para gestionar sistemas de moderación y seguridad.

Sentinel Guard no solicita deliberadamente información personal como contraseñas, datos bancarios o información de pago.

3. Uso de la información

  • Ejecutar los comandos solicitados por los usuarios.
  • Comprobar permisos y autorizaciones.
  • Proporcionar funciones de moderación y seguridad.
  • Gestionar sistemas de listas globales y cargos globales.
  • Prevenir abusos y usos indebidos del bot.
  • Mantener el funcionamiento y la seguridad del servicio.
  • Solucionar errores técnicos.

4. Global Blacklist

Sentinel Guard puede mantener información relacionada con su sistema de Global Blacklist.

Este sistema puede utilizar identificadores de Discord, como el ID de usuario, para identificar cuentas que hayan sido añadidas a la lista conforme a las funciones de administración del bot.

5. Cargos globales

Sentinel Guard puede almacenar determinados identificadores de Discord asociados a cargos globales utilizados por el sistema del bot.

Estos datos se utilizan para determinar qué funciones administrativas puede utilizar una cuenta dentro de Sentinel Guard.

6. Conservación de los datos

Sentinel Guard conservará los datos únicamente durante el tiempo necesario para proporcionar las funciones correspondientes o mientras sean necesarios para mantener los sistemas de seguridad y administración del bot.

Cuando determinados datos dejen de ser necesarios, podrán ser eliminados.

7. Compartición de información

CookedOficial no vende información personal de los usuarios.

Los datos procesados por Sentinel Guard no se compartirán deliberadamente con terceros salvo cuando sea necesario para proporcionar el funcionamiento del servicio, cumplir obligaciones legales o proteger la seguridad del bot y sus usuarios.

8. Seguridad

Se aplican medidas razonables para proteger la información procesada por Sentinel Guard frente a accesos no autorizados, modificaciones, pérdida o uso indebido.

No obstante, ningún sistema conectado a Internet puede garantizar una seguridad absoluta.

9. Servicios de terceros

Sentinel Guard utiliza la plataforma de Discord para proporcionar sus funciones. El uso de Discord está sujeto a las políticas y condiciones de Discord.

10. Derechos de los usuarios

Los usuarios pueden solicitar información sobre los datos relacionados con su cuenta que Sentinel Guard pueda conservar y, cuando corresponda, solicitar su modificación o eliminación.

Para realizar una solicitud relacionada con la privacidad de Sentinel Guard, puede contactarse con CookedOficial mediante el medio de contacto oficial proporcionado para el bot.

11. Menores

Sentinel Guard no está diseñado para recopilar deliberadamente información personal de menores.

Los usuarios deben cumplir los requisitos de edad y las condiciones de uso aplicables de Discord.

12. Cambios en esta política

Esta Política de Privacidad puede actualizarse cuando Sentinel Guard incorpore nuevas funciones, modifique la forma en que procesa información o cuando sea necesario para cumplir requisitos legales o de las plataformas utilizadas.

13. Contacto

Las consultas relacionadas con la privacidad deberán realizarse mediante el canal de contacto oficial que se indique para Sentinel Guard.
